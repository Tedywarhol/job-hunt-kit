# Logos des schémas

Les logos des outils cités dans les schémas viennent de deux collections libres. Les marques appartiennent à leurs propriétaires et ne servent ici qu'à désigner les outils que le kit relie.

| Fichiers | Source | Licence de la collection |
| :--- | :--- | :--- |
| `si-*.svg` (Notion, Gmail, Claude, Ollama, GitHub, MCP, Excalidraw, Anthropic) | [Simple Icons](https://simpleicons.org/) | CC0 |
| `dv-*.svg` (LinkedIn, Python, Chrome, React, TypeScript, Playwright, GitHub, Notion) | [Devicon](https://devicon.dev/) | MIT |

Les icônes Simple Icons sont monochromes : `kit.py` leur donne la couleur de leur marque au moment du rendu.
